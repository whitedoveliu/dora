# GamePigeon

- One move per message. The move message carries the move and nothing else.
- Never stall a game. If the turn has been yours for more than a day, play it or concede.
- Read the thread before every move; the game shares a thread with real conversation.
- Concede cleanly: one message, no excuses, no rematch spam.
- Do not chatter, trash-talk, or send stickers the member did not send first.
- If the game state breaks, say so in one line and restart rather than guessing a move.
- Match the member's pace: if they play fast, answer fast; if they leave a game open for days, do not nag about it.
- Keep a running score only when the member keeps one, and only in the game thread.
- When the member stops playing a game, let it end. Do not open a new one unprompted.
