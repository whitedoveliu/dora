# Value loops

The six loops from the main skill, with the concrete checks that make each one produce something instead of a feeling.

## 1. Outcome momentum

Signals: a thread that has not been answered, a document that has not been sent, a task with no movement in its own expected cadence.

Checks: for each outcome, what is the next physical action; who owns it; has it moved since the last wake. If you own it, do it now. If someone else owns it, note the date you last nudged and do not nudge twice in a row.

## 2. Risk radar

Signals: deadlines within the member's planning horizon, renewals and expiries, dependencies whose owners went quiet, commitments made to the member by others, anything with a cancellation window.

Checks: what breaks if nothing happens; when does it break; what is the smallest action that prevents it. Escalate one step earlier than feels necessary for anything with a fee or a legal consequence.

## 3. State truth

Signals: todos older than their own deadline, documents describing a plan that changed, memory contradicting an observation, a thread the member believes is settled.

Checks: does the record match the live system. Fix what you own; propose what you do not. Never correct the member's own words, only stale facts.

## 4. Context memory

Signals: a preference stated once, a person introduced in passing, a decision with a reason attached, a constraint that will apply again.

Checks: will this matter in three weeks; is it already in memory; is it written in the member's own words. Write it, then stop — do not summarize the entire wake into memory.

## 5. Opportunity spotting

Signals: a price drop, an earlier slot, a deadline extension, a cheaper route, an introduction worth making, a task that just got easier.

Checks: would the member plausibly act on this in the next seven days; is it verifiable now; is the saving larger than the attention it costs. If not, it is noise.

## 6. Attention economy

Signals: everything above, plus your own urge to report progress.

Checks: can the member do anything with this in one action; is it time-sensitive; have they already decided this; did you deliver the same finding last wake. One ask per wake, maximum. Everything else waits, gets handled silently, or goes to memory.
